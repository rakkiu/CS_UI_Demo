# CS_UI_Demo

Demo giao diện landing page CrabShare dựng từ [thiết kế Figma](https://www.figma.com/design/gHWUcD6CSYQmtIGnWhYkly/Untitled?node-id=67-2187) bằng React, TypeScript, Tailwind CSS và Vite.

## Chạy ở máy cá nhân

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Vercel có thể import repo này với framework **Vite**, build command `npm run build` và output directory `dist`.

Đây là bản demo giao diện. Biểu mẫu, đăng nhập và số liệu đầu tư chỉ để trình diễn, chưa kết nối backend.
